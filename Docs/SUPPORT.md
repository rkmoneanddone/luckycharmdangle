# Lucky Dangle Support

Thank you for using Lucky Dangle.

For questions, feedback, feature suggestions, or technical problems,
please contact:

**wishugreens@gmail.com**

## Reporting a Problem

When reporting a technical issue, please include:

- Windows version
- Lucky Dangle version
- What you were doing when the problem occurred
- What you expected to happen
- What actually happened
- A screenshot, if useful

## Feature Requests

Lucky Dangle is actively being developed.

You can also use the support email to suggest new dangles, collections,
interactions, or other improvements.
